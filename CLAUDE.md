# Iside – restyling di iside.promotergroup.eu

Sito mobile-first per Iside (Events | Lounge | Living), Valle dell'Ippari.
Stack: Next.js (App Router) + TypeScript + Tailwind CSS.

Segui sempre @DESIGN.md per token, componenti, accessibilità e testi.

## Regole
- Progetta a 390px di larghezza e poi allarga per gli schermi più grandi.
- Non inventare dati (prezzi, orari, capienze, recensioni): usa [DA CONFERMARE].
- Testi del sito in italiano.
- Una sezione alla volta: quando finisci, avvia `npm run dev` e dimmi cosa controllare.
